# 단위 환산

## 변경 이유

목표는 "이 기계가 지금 얼마나, 어떤 식으로 흔들리는가"를 사람이 판단할 수 있는 숫자로 만드는 것이다.

| 단계              | 하는 일                            | 왜                                                                                                                                                                                                 |
| ----------------- | ---------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ① Count → g       | 센서 숫자를 가속도(중력의 몇 배)로 | Count는 센서·설정마다 크기가 달라 비교할 수 없다. 물리 단위로 통일해야 센서끼리, 시간끼리 비교된다                                                                                                 |
| ② 시간 파형 → FFT | 흔들림을 주파수별로 나눈다         | 원인마다 진동 주파수가 다르다(회전 속도의 1배·2배, 베어링, 기어, 전기 소음 등). 어떤 주파수가 큰지 보면 원인을 짐작할 수 있다                                                                      |
| ③ 가속도 → 속도   | 주파수마다 가속도를 적분           | 기계 상태 판정 기준(ISO 10816/20816)이 **속도 mm/s RMS**다. 가속도는 높은 주파수를 크게, 변위는 낮은 주파수를 크게 보이지만, 속도는 일반 회전 기계의 손상 에너지가 몰리는 10~1000 Hz를 고르게 본다 |
| ④ SRSS            | X·Y·Z와 모든 주파수를 숫자 하나로  | 경보는 숫자 하나와 한계값을 비교해야 한다. 세 방향과 모든 주파수의 에너지를 합친 전체 크기가 SRSS다                                                                                                |

ADXL(MEMS) 전체 흐름

```text
① sensorData HEX ──디코드──> Count (축마다 N개, 보통 8192)
② Count × g/LSB ──────────> 가속도 a(t) [g]                (RAW 그래프, 시간 영역 RMS·PEAK)
③ a(t) − 평균, × 창 w ─────> FFT 단측 진폭 A(f) [g Peak]    (Window 보정)
④ A(f) / S(f), f / 1.014 ──> 보정된 가속도                   (MEMS 주파수·감도 보정, 그래프만)
⑤ A(f) × 9806.65 / (2πf) ──> 속도 V(f) [mm/s Peak]          (f > 0, 0 Hz는 0)
⑥ X·Y·Z의 V(f) 에너지 합 ──> SRSS [mm/s RMS]                (경보 기준값)
   X·Y·Z의 A(f) 에너지 합 ──> SRSS [g RMS]
```

| 단계     | 식                                                            | 코드                                                        |
| -------- | ------------------------------------------------------------- | ----------------------------------------------------------- |
| ① 디코드 | HEX 4글자 = signed int16 big-endian, ADXL은 escape 해제 안 함 | `decode.decode_vibration_samples`                           |
| ② g 환산 | `a = Count × g/LSB` (저장값 0.00380625, 공칭 1/256)           | `mems.read_mems_g_per_lsb`                                  |
| ③ FFT    | `A[k] = 2 × \|rFFT((a − 평균) × w)[k]\| / Σw`                 | `signal.fft_peak`                                           |
| ④ 보정   | `A / S(f)`, `f / 1.014`                                       | `mems.corrected_mems_fft`                                   |
| ⑤ 속도   | `V = A × 9806.65 / (2πf)`                                     | `graph_curves._adxl_converted`, `stats_calc.adxl_set_stats` |
| ⑥ SRSS   | 아래 "SRSS"                                                   | `signal.srss_axis_power`                                    |

## 1. Count — 센서가 보내는 숫자 (ADC와 비트)

### Count, LSB, 비트

센서 안의 ADC(아날로그→디지털 변환기)는 연속적인 신호(전압·가속도)를 **2^비트 개의 계단**으로 잘라 정수로 바꾼다. 그 정수가 Count다.

```text
1 LSB(= Count 1의 크기) = 측정 범위 전체 / 2^비트
물리량 = Count × (1 LSB의 크기)
```

예: 범위 32 g를 13비트(2^13 = 8192 계단)로 자르면 1 LSB = 32 / 8192 = 0.00390625 g. 비트가 많을수록 계단이 잘아서 작은 변화까지 보인다.

전송은 `sensorData` HEX 문자열이다. 4글자(2바이트)가 샘플 하나이고, **부호 있는 16비트**(2의 보수, −32768~32767)로 읽는다. 센서의 실제 비트 수가 16보다 적어도 16비트 칸에 담아(부호 확장) 보내므로 그대로 int16으로 읽으면 Count가 된다.

### ADXL(MEMS) — ADXL343 Full Resolution

MEMS 센서는 ADXL343이고 **Full Resolution 모드**로 쓴다(수신기 V057 주석과 같다). 이 모드는 측정 범위(G Range)를 키우면 비트 수도 같이 늘려서 **1 LSB 크기가 항상 같다.**

| G Range(설정 `MEMS_G_RANGE`) | 범위 폭 | 비트 | 계단 수     | 1 LSB               |
| ---------------------------- | ------- | ---- | ----------- | ------------------- |
| ±2 g (`0`)                   | 4 g     | 10   | 2^10 = 1024 | 4/1024 = 3.90625 mg |
| ±4 g (`1`)                   | 8 g     | 11   | 2^11 = 2048 | 3.90625 mg          |
| ±8 g (`2`)                   | 16 g    | 12   | 2^12 = 4096 | 3.90625 mg          |
| ±16 g (`3`)                  | 32 g    | 13   | 2^13 = 8192 | 3.90625 mg          |

그래서 공칭 환산값은 범위와 상관없이 **1/256 g/LSB = 0.00390625 g**(256 LSB/g)다. "13비트"는 ±16 g일 때의 비트 수다.

| 값                                | g/LSB      | LSB/g  | 비고                                                      |
| --------------------------------- | ---------- | ------ | --------------------------------------------------------- |
| 공칭(데이터시트)                  | 0.00390625 | 256    | 1/256                                                     |
| 지금 저장값 `mems_lsb_scale.json` | 0.00380625 | 262.73 | 공칭보다 2.6% 작다. 실측으로 맞춘 개별 보정값으로 쓰는 중 |

- 왜 Count에 g/LSB를 곱하나: Count는 "몇 계단인지"일 뿐이다. 1 계단이 몇 g인지(g/LSB)를 곱해야 가속도가 된다.
- 주의: 펌웨어가 Full Resolution이 아닌 10비트 고정 모드라면 범위에 따라 1 LSB가 달라진다(±16 g면 31.25 mg). 웹은 1/256 고정을 가정하므로, G Range를 바꿔 쓸 때는 펌웨어 모드를 확인해야 한다.
- 샘플링 속도 코드 `0x08`~`0x0F`는 ADXL343의 출력 속도 레지스터 값이다(25, 50, 100, 200, 400, 800, 1600, 3200 Hz). 웹은 Hz와 코드를 모두 Hz로 읽는다(`normalize_sample_rate`).

### PIEZO — 12비트 눈금 시험 적용

압전(PIEZO) 센서는 진동을 전압으로 내고, 그 전압을 ADC가 Count로 바꾼다.

```text
전압 [mV] = Count × 1000 × Vmax / Amax        (K = 1000 × Vmax / Amax  [mV/Count])
가속도 [g] = 전압 [mV] / 감도 [mV/g]
```

| 값   | 기본        | 뜻                                |
| ---- | ----------- | --------------------------------- |
| Amax | 4096 = 2^12 | 12비트 ADC의 계단 수로 가정       |
| Vmax | 3.89 V      | ADC 기준 전압(4096 계단 = 3.89 V) |
| 감도 | 100 mV/g    | 센서가 1 g에 내는 전압            |

`K = 1000 × 3.89 / 4096 = 0.94970703125 mV/Count`

- 주의: 받는 값은 16비트 signed인데 12비트 ADC 눈금(4096)을 **시험으로** 적용한 것이다(V011부터 이어진 데스크톱 주석: "12-bit voltage scaling here is an experimental scale applied to original 16-bit words"). 절대 전압으로 확정하지 않는다.
- ADC 0점(중앙값, 예: Amax/2)은 평균을 빼면 사라지므로 따로 빼지 않는다.

## 2. 시간 축

```text
시간(s) = n / Fs        (n: 샘플 번호, Fs: 샘플링 속도 Hz)
```

발생기·분석 화면은 시간 ms, 주파수 kHz, 수신 모니터는 s, Hz로 표시한다. 눈금만 다르다.

## 3. FFT — 시간 파형을 주파수별로

```text
Count Peak[k] = 2 × |rFFT( (x − 평균) × w )[k]| / Σw        (x: Count 또는 g)
f[k] = k × Fs / N        (칸 간격 Δf = Fs / N)
```

| 처리                         | 왜                                                                                                                         |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| 평균을 뺀다                  | 평균(0 Hz, 직류)은 중력·센서 0점이지 진동이 아니다. 남겨 두면 0 Hz 칸이 커지고 창 때문에 옆 칸으로 번진다                  |
| 창 w를 곱한다(기본 Blackman) | FFT는 패킷 끝과 처음이 이어진다고 본다. 끝이 맞지 않으면 없는 주파수가 생긴다(누설). 창은 양 끝을 0으로 줄여 이것을 막는다 |
| Σw로 나눈다(진폭 보정)       | 창이 신호를 깎은 만큼(Blackman은 평균 약 0.42배) 되돌린다. 그래서 진폭 A인 사인파는 그 칸에서 A로 나온다                   |
| ×2 (단측)                    | 실수 신호의 FFT는 +f와 −f에 반씩 나뉜다. 양수 쪽만 보므로 2배 한다. 0 Hz와 짝수 N의 Nyquist(Fs/2)는 짝이 없어 2배 안 한다  |
| Peak ÷ √2 = RMS              | 사인파의 RMS는 진폭의 1/√2다. 'g RMS' 단위는 이 값이다                                                                     |

Fs 3200 Hz, N 8192면 Δf = 0.390625 Hz이고, 칸은 0, 0.39, 0.78 … 1600 Hz다. 볼 수 있는 가장 높은 주파수는 Fs/2(1600 Hz)다(Nyquist).

FFT 그래프의 한 칸 값은 그 주파수 하나의 크기다. 파형 전체의 크기는 아래 SRSS(또는 시간 영역 RMS)다.

### Window 보정 선택(화면)

| Window 보정     | FFT 칸 값   | 언제 맞나                                       |
| --------------- | ----------- | ----------------------------------------------- |
| 보정 없음       | `÷N`        | 창 감쇠가 그대로 남는다(Blackman이면 약 0.42배) |
| 진폭 보정(기본) | `÷Σw`       | 사인파(한 주파수에 몰린 진동)의 peak가 정확     |
| 에너지 보정     | `÷√(N·Σw²)` | 잡음처럼 넓게 퍼진 신호의 RMS가 정확            |

SRSS는 아래처럼 언제나 에너지 기준으로 다시 맞추므로 진폭·에너지 보정 어느 쪽이든 같다.

## 4. PIEZO 표시 단위

RAW는 평균을 뺀 Count에 단위만 곱한다.

| 표시     | RAW Y                     | FFT Y                          |
| -------- | ------------------------- | ------------------------------ |
| Count    | Count − 평균              | Count Peak                     |
| mV       | (Count − 평균) × K        | Count Peak × K                 |
| g RMS    | (Count − 평균) × K / 감도 | Count Peak × K / (감도 × √2)   |
| mm/s RMS | RAW는 g와 같음            | g RMS × 9806.65 / (2πf), f > 0 |

진폭 1000 Count, 1000 Hz 사인파, 기본값:

| 단계         | 값                   |
| ------------ | -------------------- |
| RAW mV       | 949.70703125 mV      |
| RAW g        | 9.4970703125 g       |
| FFT g RMS    | 6.715442819 g RMS    |
| FFT mm/s RMS | 10.48130751 mm/s RMS |

PIEZO FFT에는 아래 MEMS 보정을 적용하지 않는다.

## 5. ADXL 표시 단위

```text
RAW g  = Count × (g/LSB)
g Peak = Count Peak × (g/LSB)
g RMS  = Count Peak × (g/LSB) / √2
전체 AC g RMS = 표준편차(Count × g/LSB)
```

RAW 파형은 평균을 빼지 않는다(중력 성분까지 보이게). FFT와 전체 AC RMS만 평균을 뺀다.

자동 눈금은 환산한 g의 최댓값으로 고른다. 식은 같고 표시만 10³ 또는 10⁶을 곱한다. X/Y/Z는 같은 눈금을 쓴다(중력이 있는 축만 g, 나머지가 mg가 되어 한 그래프에서 비교가 안 되는 것을 막는다).

| 최댓값            | RAW | FFT    |
| ----------------- | --- | ------ |
| 1 이상            | g   | g RMS  |
| 0.001 이상 1 미만 | mg  | mg RMS |
| 0.001 미만        | µg  | µg RMS |

직접 고르면 배율은 고정이다.

| 표시       | 배율         |
| ---------- | ------------ |
| Count      | 1            |
| g          | g/LSB        |
| mg         | 1000 × g/LSB |
| µg         | 10⁶ × g/LSB  |
| Count Peak | 1            |
| g Peak     | g/LSB        |
| g RMS      | (g/LSB) / √2 |

공칭 0.00390625 g/LSB, Count Peak 1000: g Peak 3.90625 g, g RMS 2.762135864 g RMS.

## 6. MEMS 주파수·감도 보정 (그래프만)

```text
G_final = G / S(f)
f_final = f / 1.014
```

- 왜: MEMS 센서는 모든 주파수에서 같은 크기로 반응하지 않는다(높은 주파수로 갈수록 출력이 작아진다). S(f)로 나눠 그만큼 키우고, 주파수 축도 1.014로 나눠 실제 주파수에 맞춘다. 값은 수신기 V057·발생기 v070과 같다.
- 기본값은 둘 다 켜져 있다. 감도는 나누기 전 측정 주파수 f로 계산한 뒤 주파수를 나눈다.
- `G`는 g Peak 또는 g RMS다. Count Peak는 S(f)로 나누지 않는다. 주파수 나눗셈은 Count Peak에도 적용한다.
- 통계(`measurement`)에는 적용하지 않는다(아래 "그래프와 통계가 다른 점").

| f                  | S(f)                                              |
| ------------------ | ------------------------------------------------- |
| f ≤ 60 Hz          | 0.99                                              |
| 60 Hz < f ≤ 360 Hz | 1.07 − 0.0005 × f (60 Hz 직후 1.04 → 360 Hz 0.89) |
| f > 360 Hz         | 0.89                                              |

예: g RMS 2.762135864가 1089 Hz에 있으면 S = 0.89 → G_final = 3.103523443 g RMS, f_final = 1089 / 1.014 = 1073.964497 Hz.

## 7. 가속도 → 속도

```text
V(f) [mm/s] = A(f) [g] × 9806.65 / (2π × f)
```

- **왜 속도로 보나**: 위 "큰 그림" ③. 기계 진동 판정 기준이 속도 mm/s RMS다.
- **9806.65**: g를 mm/s²로 바꾸는 수다. 1 g = 표준 중력가속도 9.80665 m/s² = 9806.65 mm/s². 진동 속도는 관례(ISO 포함)대로 mm/s로 보려고 mm 기준 값을 곱한다(m/s로 보려면 9.80665).
- **f**: 그 FFT 칸의 주파수 [Hz] = 1초에 흔들리는 횟수. 2πf는 각주파수 ω [rad/s]다.
- **2πf로 나누는 이유**: 속도는 가속도를 시간으로 적분한 것이다. FFT가 신호를 주파수 f인 사인파들로 나눠 주므로 사인파마다 적분한다.

```text
a(t) = A·sin(2πf·t)   [mm/s²]
v(t) = ∫a dt = −A/(2πf)·cos(2πf·t)   → 속도 진폭 = A / (2πf)
단위: (mm/s²) ÷ (1/s) = mm/s
```

예: 100 Hz에서 1 g → 1 × 9806.65 ÷ (2π × 100) = 15.6 mm/s. 0 Hz 칸은 0으로 나눌 수 없어 0으로 둔다(직류는 진동이 아니다). 그래프는 주파수 보정이 켜져 있으면 `f/1.014`로 나누고, 통계는 원래 f로 나눈다.

같은 1 g라도 주파수가 낮을수록 속도가 크게 나온다(천천히 흔들리면 한 번 움직이는 시간이 길어 속도가 많이 붙는다).

| f               | 1 g일 때 속도 |
| --------------- | ------------- |
| 0.39 Hz (첫 칸) | 3995.6 mm/s   |
| 1 Hz            | 1560.8 mm/s   |
| 2 Hz            | 780.4 mm/s    |
| 10 Hz           | 156.1 mm/s    |
| 100 Hz          | 15.6 mm/s     |
| 1000 Hz         | 1.56 mm/s     |

그래서 **아주 낮은 주파수의 작은 가속도(센서 드리프트, 기울기 변화, 평균 제거 뒤 남은 느린 흔들림)도 속도로 바꾸면 커진다.** 진동 속도 평가는 보통 10~1000 Hz(저속 기계는 2~1000 Hz) 대역으로 한다(ISO 10816/20816). 지금 웹은 대역을 자르지 않는다(아래 "검증 결과").

## 8. RMS 세 가지

RMS(Root Mean Square, 제곱평균의 제곱근)는 흔들림의 "평균적인 크기"다. 순간 최댓값(PEAK)보다 에너지를 잘 나타내서 진동 평가에 쓴다. 이름이 같아도 뜻이 다르다.

| 이름       | 식                                         | 쓰는 곳                          |
| ---------- | ------------------------------------------ | -------------------------------- |
| 축 AC RMS  | `√mean((a − 평균)²)` = 표준편차. 시간 영역 | 정보 칩 `X AC g RMS=…`           |
| 합성 RMS   | `√(RMS_X² + RMS_Y² + RMS_Z²)`              | 통계 `rms`(통계 화면 'RMS 평균') |
| FFT 칸 RMS | `A(f) / √2` (그 주파수 하나의 RMS)         | FFT 그래프 g RMS·mm/s RMS 눈금   |

PEAK(통계)는 세 축의 `max|a − 평균|` 중 가장 큰 값(g)이다. 시간 영역 순간 최댓값이다. PEAK/RMS 비(Crest factor)가 크면 충격성 진동(베어링 초기 결함 등)일 수 있다.

## 9. SRSS — 전체 크기 하나

SRSS(Square Root of Sum of Squares, 제곱합의 제곱근)는 FFT 칸들의 에너지를 모두 더해 낸 **전체 AC RMS 숫자 하나**다. 축마다 더한 뒤 X·Y·Z를 합친다.

```text
P_축 = Σ_k ( c_k × A[k]² ) × (Σw)² / (N × Σw²)
       c_k: 0 Hz = 0, 짝수 N의 Nyquist = 1, 나머지 = 0.5   (A는 Peak → RMS² = A²/2)
SRSS = √(P_X + P_Y + P_Z)
```

| 처리                              | 왜                                                                                                                                                                          |
| --------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 제곱해서 더한다                   | 서로 다른 주파수의 진동은 에너지(제곱)끼리 더해진다. 진폭을 그냥 더하면 실제보다 커진다                                                                                     |
| `(Σw)² / (N × Σw²)` (에너지 보정) | ③에서 진폭 기준(Σw)으로 맞춘 값을 창 에너지(Σw²) 기준으로 다시 맞춘다. 창이 깎은 에너지를 되돌리는 것으로, 이 덕분에 SRSS(g)가 시간 영역 합성 RMS와 같아진다(Parseval 정리) |
| X·Y·Z를 제곱합                    | 세 방향 진동 에너지를 합친 전체 크기. 한 방향만 보면 다른 방향 이상을 놓친다                                                                                                |

- A에 g를 넣으면 SRSS [g RMS], ⑤의 속도 V를 넣으면 SRSS [mm/s RMS]. 경보는 mm/s RMS와 한계(기본 4.5)를 비교한다.
- 화면 'Window 보정'이 '보정 없음'일 때만 `√mean(w²)`를 곱해 창 감쇠가 남은 값이 된다. 진폭·에너지 보정이면 같다.

## 10. 필터

단위를 곱하기 전에, RAW와 FFT에 따로 켤 수 있다. 패킷 하나를 FFT해서 크기만 곱하고 되돌린다(위상 0). `f`는 Hz, 차수는 기본 4, Notch 폭은 기본 20 Hz다.

```text
HPF = 1 / √(1 + (fc / f)^(2 × 차수))       낮은 주파수를 줄인다(드리프트·기울기 변화 제거)
LPF = 1 / √(1 + (f / fc)^(2 × 차수))       높은 주파수를 줄인다(관심 밖 고주파·잡음 제거)
σ   = 폭 / (2 × √(2 × ln 2))
Notch = 1 − exp(−0.5 × ((f − fc) / σ)²)    한 주파수만 판다(전원·특정 공진 소음 제거)
```

- 기본 차단 주파수: PIEZO HPF 10 Hz, LPF 3000 Hz. ADXL HPF 10 Hz, LPF 1000 Hz. Notch 중심 975 Hz.
- LPF '자동 Fs/2'(기본 켜짐)이면 LPF를 걸지 않는다. 필터는 기본으로 모두 꺼져 있다.
- 왜 필요한가: 위 7의 저주파 문제처럼 관심 대역 밖 성분이 속도·SRSS를 키울 때, FFT 쪽 HPF(예: 10 Hz)를 켜면 판정 대역만 남는다. 통계에는 적용하지 않는다.
