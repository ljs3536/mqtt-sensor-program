# 단위 환산

수신값 `sensorData`는 부호 있는 16비트 Count다. 아래 식은 그래프에만 적용된다.

```text
시간(s) = n / Fs
```

발생기는 시간을 ms, 주파수를 kHz로 표시한다. 모니터는 s, Hz다. 나누고 곱하는 눈금만 다르다.

## FFT → Count Peak

구간 평균을 빼고 창을 곱한 뒤 실수 FFT를 한다. 0 Hz와 나이퀴스트 칸은 2를 곱하지 않는다.

```text
Count Peak[k] = 2 × |rFFT( (Count − 평균) × 창 )[k]| / Σ창
```

사인파 진폭 A Count이면 그 주파수 칸의 Count Peak는 A다. 그 칸의 RMS는 A / √2다.

파형 전체 AC RMS는 한 칸의 값이 아니다.

```text
전체 AC RMS = 표준편차(환산된 파형)
```

## PIEZO

```text
K = 1000 × Vmax / Amax
```

기본값: Vmax = 3.89 V, Amax = 4096(2의 12제곱), 감도 = 100 mV/g.

```text
K = 1000 × 3.89 / 4096 = 0.94970703125 mV/Count
```

RAW는 평균을 뺀 Count에 단위만 곱한다.

| 표시 | RAW Y | FFT Y |
| --- | --- | --- |
| Count | Count − 평균 | Count Peak |
| mV | (Count − 평균) × K | Count Peak × K |
| g RMS | (Count − 평균) × K / 감도 | Count Peak × K / (감도 × √2) |
| mm/s RMS | RAW는 g와 같음 | g RMS × 9806.65 / (2πf), f > 0 |

진폭 1000 Count, 1000 Hz 사인파, 기본값:

| 단계 | 값 |
| --- | --- |
| RAW mV | 949.70703125 mV |
| RAW g | 9.4970703125 g |
| FFT g RMS | 6.715442819 g RMS |
| FFT mm/s RMS | 10.48130751 mm/s RMS |

PIEZO FFT에는 아래 ADXL 보정을 적용하지 않는다.

## ADXL

기본 환산은 1 LSB당 g다.

| 값 | g/LSB | LSB/g |
| --- | --- | --- |
| 공칭 1/256 | 0.00390625 | 256 |
| 이 저장값 `mems_lsb_scale.json` | 0.00380625 | 262.725779967 |

```text
RAW g = Count × (g/LSB)
g Peak = Count Peak × (g/LSB)
g RMS  = Count Peak × (g/LSB) / √2
```

RAW 파형은 평균을 빼지 않는다. FFT와 전체 AC g RMS만 평균을 제거한다.

```text
전체 AC g RMS = 표준편차(Count × g/LSB)
```

자동 눈금은 환산한 g의 최댓값으로 고른다. 식은 같고 표시만 10³ 또는 10⁶을 곱한다.

| 최댓값 | RAW | FFT |
| --- | --- | --- |
| 1 이상 | g | g RMS |
| 0.001 이상 1 미만 | mg | mg RMS |
| 0.001 미만 | µg | µg RMS |

직접 고르면 배율은 고정이다.

| 표시 | 배율 |
| --- | --- |
| Count | 1 |
| g | g/LSB |
| mg | 1000 × g/LSB |
| µg | 10⁶ × g/LSB |
| Count Peak | 1 |
| g Peak | g/LSB |
| g RMS | (g/LSB) / √2 |

공칭 0.00390625 g/LSB, Count Peak 1000:

| 단계 | 값 |
| --- | --- |
| g Peak | 3.90625 g |
| g RMS | 2.762135864 g RMS |

## ADXL FFT 최종 보정

기본값은 둘 다 켜져 있다. 감도는 나누기 전 측정 주파수 `f`로 계산하고, 그 다음 X를 나눈다.

```text
G_final = G / S(f)
f_final = f / 1.014
```

`G`는 g Peak 또는 g RMS다. Count Peak는 `S(f)`로 나누지 않는다. 주파수 나눗셈은 Count Peak에도 적용한다.

| f | S(f) |
| --- | --- |
| f ≤ 60 Hz | 0.99 |
| 60 Hz < f ≤ 360 Hz | 1.07 − 0.0005 × f |
| f > 360 Hz | 0.89 |

구간 경계:

| f | S(f) |
| --- | --- |
| 60 Hz | 0.99 |
| 60 Hz를 넘는 직후 | 1.04 |
| 360 Hz | 0.89 |
| 360 Hz 초과 | 0.89 |

위 예의 g RMS 2.762135864를 1089 Hz에 두면 S = 0.89이다.

| 단계 | 값 |
| --- | --- |
| G_final | 2.762135864 / 0.89 = 3.103523443 g RMS |
| f_final | 1089 / 1.014 = 1073.964497 Hz |

## 초음파

Count를 g로 바꾸지 않는다. 패킷 안의 float 320개를 그대로 Y에 그린다.

```text
f(kHz) = 시작(kHz) + 칸 번호 × 간격(Hz) / 1000
```

## 필터

단위를 곱하기 전에, RAW와 FFT에 따로 켤 수 있다. `f`는 Hz, 차수는 기본 4, Notch 폭은 기본 20 Hz다.

```text
HPF = 1 / √(1 + (fc / f)^(2 × 차수))
LPF = 1 / √(1 + (f / fc)^(2 × 차수))
σ   = 폭 / (2 × √(2 × ln 2))
Notch = 1 − exp(−0.5 × ((f − fc) / σ)²)
```

기본 차단 주파수: PIEZO HPF 10 Hz, LPF 3000 Hz. ADXL HPF 10 Hz, LPF 1000 Hz. Notch 중심 975 Hz.
