# 웹 / 프로그램 기능 대조

기준은 지금 폴더의 최신 프로그램과 8080 `web`이다. 8081 `web_db`는 이 표와 다른 곳이 있다.

- `web_db` 수신 모니터에는 센서 타입 0~4, 설명 문구, G Range(`MEMS_G_RANGE`), PIEZO 게인(`PIEZO_GAIN`)이 있다. START는 collection 3(PIEZO) 또는 4(MEMS)이고, `MEMS_SAMPLE_RATE`의 `0x`를 뺀다.
- `web_db`도 설정 명령은 QoS 0이다. STOP은 `SENSORTYPE 0` retain 한 번이고, 프로그램의 3단계 STOP·PUBACK 대기와 명령 길이 검사는 없다.
- `web_db`의 SQLite 저장, 통계, 설정 화면은 `docs/웹-DB-화면역할.md`에 있다.

| 구분 | 프로그램 | 웹 |
| --- | --- | --- |
| 수신 | `new_piezo_adc_V052.py` | `/` 센서 수신 모니터 |
| 발생 | `mqtt_wave_replay_generator_v055_pyqtgraph.py` | `/generator`, `/studio` (계산·송신은 같음) |

O는 그 화면에서 쓸 수 있다는 뜻이다. X는 없다. 둘 다 O여도 보내는 값이나 화면이 다르면 비고에 적었다.

## 수신기 — 설정 전송

웹 모니터의 설정 칸은 종류, 주기, Fs+N, START, STOP, 설정 적용, 현재 설정 조회, JSON 미리보기까지다. V052는 그 옆에 **센서 타입 0~4**, **G Range**, **PIEZO 게인**이 있고, START와 STOP의 전송 내용이 다르다. 이 칸과 전송 절차는 웹에 없다.

| 기능 | Web | Program | 비고 |
| --- | --- | --- | --- |
| 브로커, 포트, 구독 토픽 | O | O | 웹 기본 브로커 `127.0.0.1`, 구독 `V/#,D/#` |
| 구독 QoS 선택 (0/1/2) | X | O | 웹 구독은 QoS 0 고정. 사용자가 고른 토픽에 `S/#`를 더함 |
| MQTT User / Password | X | X | 수신기 V052 화면에도 없음 |
| 시리얼 COM, Baud | X | O | |
| 수신 MAC 목록, 전체 선택, 선택 해제 | O | O | 프로그램은 목록 새로고침 버튼이 따로 있음. 웹은 1초 상태 조회로 목록이 갱신됨 |
| MAC 직접 입력 | O | X | 웹만. 대상 추가 버튼은 웹에도 없음 |
| 보내기 전 MAC 확인 문구 | O | X | |
| 종류 PIEZO / ADXL | O | O | |
| 측정 주기(초) | O | O | |
| Fs + N 프로필 | O | O | PIEZO 512~25600 Hz, ADXL 100~3200 Hz, 개수 1024~8192 |
| 센서 타입 0~4 선택 | X | O | 0 종료, 1 PIEZO normal, 2 MEMS normal, 3 PIEZO collection, 4 MEMS collection |
| 센서 타입 설명 문구 | X | O | |
| G Range 2/4/8/16 | X | O | 송신 키 `MEMS_G_RANGE` 코드 0/1/2/3. 화면 LSB와는 별개 |
| PIEZO 게인 | X | O | 송신 키 `PIEZO_GAIN`. ADXL일 때는 칸이 비활성 |
| 전송 JSON 미리보기 | O | O | |
| 설정 적용 | O | O | 웹은 SENSORTYPE 1 또는 2와 주기, 샘플만 보냄. 프로그램은 선택한 0~4와 게인 또는 G Range를 포함 |
| START | O | O | 웹 START는 설정 적용과 같은 1/2. 프로그램 START는 collection 3(PIEZO) 또는 4(ADXL) |
| STOP | O | O | 웹은 `SENSORTYPE 0`과 주기만 retain. 프로그램은 QoS 1로 STOP retain → 빈 payload로 retain 삭제 → normal 1/2 retain, 각 단계 PUBACK 대기 |
| 설정 명령 QoS 1 | X | O | 웹 `S/{MAC}` 명령은 QoS 0 |
| retain 명령 끝에 CR LF | O | O | |
| `MEMS_SAMPLE_RATE`에서 `0x` 제거 | X | O | 웹은 `0x08`~`0x0F` 문자열 그대로. 프로그램은 `08`~`0F` |
| 현재 설정 조회 (`CONFIG ?`) | O | X | 프로그램은 버튼 객체가 있으나 화면에 올리지 않음. 웹은 버튼이 있고 MAC 1개만 허용 |
| 명령 길이 1024바이트 검사 | X | O | |
