# 웹 / 프로그램 기능 대조

2026-11-19 기준. 웹 = `web_db`(지금 8080·Docker로 띄우는 것), 프로그램 = 이 폴더의 최신 데스크톱 프로그램이다.

| 구분 | 프로그램 | 웹 화면 |
| --- | --- | --- |
| 수신기 | `new_piezo_adc_V057_window_ratio_fix.py` | 센서 수신 모니터 `/receiver` |
| 발생기 | `mqtt_wave_replay_generator_v070_pyqtgraph_rms_history_xy_zoom_pin.py` | 데이터 분석 CSV `/generator`, 센서 데이터 분석 `/studio`(DB) |
| (없음) | | 센서 현황 `/`, 통계 `/dashboard`, 설정 `/settings` — 웹에만 있다 |

O = 그 화면에서 쓸 수 있다. X = 없다. 둘 다 O여도 보내는 값이나 화면이 다르면 비고에 적었다.
예전 `web`(이전 웹)과 수신기 V052·발생기 v055 기준 표는 이 문서로 대체했다. 각 기능이 CSV·DB 중 어디를 쓰는지는 `docs/웹-기능상세.md` "데이터는 어디서 오나".

## 발생기 — 분석, 송신

웹은 발생기를 두 화면으로 나눴다. 계산과 송신은 같고 데이터 출처만 다르다.

- `/generator` 데이터 분석 CSV: 올린 파일(CSV·JSON). DB는 읽지 않는다.
- `/studio` 센서 데이터 분석: SQLite `packet`(MAC, 최근 N세트 또는 기간).

| 기능 | 웹 | 프로그램 | 비고 |
| --- | --- | --- | --- |

| ADXL X/Y/Z CSV 세 개, `packet_no` 세트 묶기(안 되면 seq) | O | O | |
