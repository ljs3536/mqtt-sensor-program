# 웹 / 프로그램 기능 대조

2026-11-23 기준: 수신기 **V063**, 발생기 **v073**(전에는 V057·v070). 웹 = `web_db`(지금 8080·Docker로 띄우는 것), 프로그램 = 이 폴더의 최신 데스크톱 프로그램이다.
11-23: 두 버전에서 바뀐 기능(아래 '2026-11-23 V063·v073 대조')을 프로그램 함수를 직접 불러 같은 데이터로 계산해 비교했다(결과 `web_db-기능-테스트-결과.md`).
11-20: 센서 명령 QoS·STOP 3단계·CR LF·1024바이트, 구독 QoS, 클릭 커서, CSV 상태 메타데이터 열을 프로그램과 맞춤.

| 구분 | 프로그램 | 웹 화면 |
| --- | --- | --- |
| 수신기 | `new_piezo_adc_V063_axis_units_aligned.py` (창 제목은 'V056 — 실시간 PSD / 연산결과 CSV'로 남아 있음) | 센서 수신 모니터 `/receiver` |

| (없음) | | 센서 현황 `/`, 통계 `/dashboard`, 설정 `/settings` — 웹에만 있다 |

O = 그 화면에서 쓸 수 있다. X = 없다. 둘 다 O여도 보내는 값이나 화면이 다르면 비고에 적었다.
예전 `web`(이전 웹)과 수신기 V052·발생기 v055 기준 표는 이 문서로 대체했다. 각 기능이 CSV·DB 중 어디를 쓰는지는 `docs/웹-기능상세.md` "데이터는 어디서 오나".
