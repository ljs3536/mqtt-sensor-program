# 센서 현황 작업 (피드백 반영)

센서 현황(대문 `/`) 화면에 받은 피드백과 그 작업 목록이다. 작업하면서 체크한다.
관련 문서: `docs/대문-평면도-대시보드-계획.md`(처음 계획), `docs/웹-DB-화면역할.md`(화면 동작).

## 받은 피드백 (2026-11-23)

- 좌측 상단 알림을 초음파/진동으로 구분
  - 총 몇 개 센서 중 몇 개가 이상인지 표시
  - 진동과 초음파 각각 이상 신호의 용어 정리와 단계 구분(예: 초음파 = 누출, 진동 = 진동 이상, 단계 2개)
- 우측 센서 목록을 숨길 수 있게
  - 센서 목록의 '대기'가 무엇인지 궁금해함
- 평면도 아이콘을 누르면 팝업에 사진 포함
  - 사진 + 정보
  - MEMS/PIEZO 대신 Type1, Type2처럼 쉬운 이름
  - 아이콘의 이상 표시(예: 끊김 = 느낌표)를 센서 목록에도 똑같이
- 센서 '자세히 보기' → 통계가 아니라 분석 화면으로
  - 그 센서 MAC 선택과 조회가 자동으로 되어 분석 그래프까지

## 진행 기록

### 2026-11-23 — 1번, 2번 완료

**1. 자세히 보기 → 분석 화면 자동 조회**

- 팝업 아래 링크: **'자세히 보기 →'**(주 버튼, 센서 데이터 분석) + '통계 보기'(그대로 둠).
- 누르면 `/studio`로 가서 자동으로: 센서 종류 탭 고르기(MEMS / PIEZO / 초음파) → MAC 선택 → 조회 → 그래프.
- 주소에 MAC을 남기지 않는다. `sessionStorage('studio-focus')`에 `{mac, kind}`를 넣고 분석 화면이 한 번 읽고 지운다(새로고침하면 다시 열지 않음). 통계 화면 강조와 같은 방식.
- 수신 기록이 없는 MAC(설정만 있는 장치)은 "저장된 수신 기록이 없어 열 수 없습니다"를 보여 준다.
- 파일: `static/site.js`(팝업 링크), `static/db.js`(자동 조회), `static/site.css`.

**2. 센서 목록 숨기기**

- 위쪽 오른쪽 **☰** 버튼(누를 때마다 숨김/보임), 목록 머리의 **»** 버튼(숨김).
- 숨기면 평면도가 화면 폭을 다 쓴다(1600 px 화면에서 평면도 1247 → 1557 px). 확대 중이면 범위를 다시 맞춘다.
- 숨김 상태는 브라우저에 기억한다(`localStorage 'site-list-hidden'`). 설정 '평면도 배치'에는 없다(배치할 때는 목록이 필요).
- 파일: `site.html`, `static/site.js`, `static/site.css`.

**확인**

- 브라우저 자동 조작: MEMS(165874312270)와 초음파(2A596F383F70) 각각 팝업 → 자세히 보기 → 탭·MAC 선택·조회까지 자동(50세트 열림), 넘긴 값은 지워짐. 목록 숨김·새로고침 뒤 유지·다시 보이기·» 버튼 모두 정상.
- HTTP 점검 119/119.


### 2026-11-23 — 3·4·5·6번 완료

**3. 위쪽 요약**

- 진동(Type1·Type2) / 초음파(Type3) 두 카드. 카드마다 `총 N개`, `상태 [경보 n] [위험 n]`, `수신 [정상 n] [이상 n] [확인 불가 n]`.
- 수신 '이상' = 지연 + 미수신. 서버가 센서마다 `link_group`(ok / bad / unknown)을 같이 준다.
- 기준이 없는 Type1·Type3은 상태 줄에 '기준 없음(표시만)'.
- 칩을 누르면 그 묶음·상태만 강조하고 목록도 거른다(예: `vib:alarm`). 다시 누르면 풀린다.

**4. 이름**

- 끊김 → **미수신**, 대기 → **확인 불가**. 단계 이름: 주의 → **경보**(80% 이상), 경보 → **위험**(한계 이상). 수신 지연은 따로 **지연**(노랑).
- 상태 순서: 위험 > 미수신 > 경보 > 지연 > 정상 > 확인 불가. 확인 불가 이유(수신 꺼짐·측정 중지·데이터 없음 등)는 목록 둘째 줄과 카드에 그대로 보인다.
- 최근 알림 '확인 안 한 것'에 지연도 센다.

**5. 종류 이름**: Type1 = PIEZO 진동, Type2 = MEMS 진동, Type3 = 초음파. 목록·카드·범례·요약에 쓴다.

**6. 아이콘**

- `iconHtml()` 하나를 평면도 아이콘·목록·정보 카드가 같이 쓴다: 색 = 상태, 안 그림 = 종류, 오른쪽 위 빨간 '!' = 배터리 부족(3 이하).
- 목록 오른쪽: 상태 글씨 알약 + 배터리. 범례: 상태 6개, '! 배터리 부족', 종류 그림 3개.
- 파일: `src/site_status.py`, `src/store_site.py`, `static/site.js`, `static/site.css`, `site.html`.

**확인**: 브라우저 자동 조작으로 요약·칩 거르기(위험 → 2개만 남고 5개 흐림)·목록 아이콘·범례·카드 확인. HTTP 점검 119/119.

### 2026-11-23 — 요약 한 줄, 7번 사진

**요약 한 줄(3번 다듬기)**: 진동·초음파 카드마다 '이름 총 N개 | 상태 [경보][위험] | 수신 [정상][이상][확인 불가]' 한 줄. '기준 없음' 글씨는 뺐다. 기준이 없는 종류는 경보·위험이 0으로 보이고, 기준이 생기면 같은 자리에 숫자가 더해진다.

**7. 센서 사진**

- 설정 → 장치 · 수신 표에 '사진' 칸: 올리기/바꾸기/삭제, 작은 미리보기(누르면 크게).
- 올리기 전에 브라우저가 긴 변 1600px JPEG로 줄인다(휴대폰 사진 수 MB → 수백 KB 이하).
- 저장: `site_files/sensor_photos/{MAC}.jpg`(평면도 이미지 옆, Docker는 `/data/site_files`라 이미 마운트된 곳). DB 테이블은 쓰지 않는다.
- 서버 확인: PNG·JPG·WEBP 확장자 + 파일 첫 바이트(가짜 이미지 거부), 15MB, MAC은 영문·숫자·_-만(경로 조작 막기).
- 대문 정보 카드 맨 위에 사진(높이 170px 고정, 잘리지 않게 contain). 누르면 원본을 새 탭으로. 상태 API의 `photo` 주소 끝 `?v=수정 시각`이라 바꾸면 바로 새 사진.
- 파일: `src/store_site.py`, `src/routes/site.py`, `src/routes/db.py`(장치 목록에 photo), `static/settings.js`, `settings.html`, `static/site.js`, `static/site.css`.

**확인**: 사진 API(올리기·가짜 파일 거부·경로 조작 404·nosniff), 브라우저에서 파일 고르기 → 3000px가 1600px로 줄어 저장, 대문 카드 사진. HTTP 점검 119/119.
