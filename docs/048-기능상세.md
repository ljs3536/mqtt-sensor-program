# 048 데스크톱 프로그램 기능 상세

대상은 다음 두 파일이다.

- 발생기: `mqtt_wave_replay_generator_v048_pyqtgraph.py`
  창 제목 `발생기 V048 — SRSS / FFT 과정 검증`
- 수신기: `new_piezo_adc_V048.py`
  파일 이름은 V048이다. 창 제목 문자열은 `수신기 V046 — 그래프 기본 너비 조정`으로 남아 있다.

둘 다 Tkinter 메인 창과 PyQtGraph 그래프 창을 쓴다. 그래프 계산은 NumPy FFT다. 수신기에는 SciPy 비교 그래프가 하나 더 있다. MQTT는 paho-mqtt Callback API v2다.

표시용 환산, 필터, SRSS, 창 함수는 그래프에만 적용된다. 수신 HEX, 저장 CSV의 `sensorData`, 발생기가 보내는 JSON payload의 센서 데이터는 이 계산으로 다시 쓰지 않는다.

## 공통으로 쓰는 계산

### 샘플 해석

진동 패킷의 `seq` 상위 nibble이 센서 종류다.

| 상위 nibble | 의미 |
| --- | --- |
| 0 | PIEZO |
| 1 | ADXL X |
| 2 | ADXL Y |
| 3 | ADXL Z |

하위 nibble은 0~F 순환 번호다. 발생기는 `SequenceState.next_seq`, 수신기는 `parse_seq`와 `classify_vibration`이 이 규칙을 쓴다.

`sensorData`는 HEX 문자열이다. 4글자마다 signed int16, big-endian(`>i2`)이다. PIEZO는 `7D 5E → 7E`, `7D 5D → 7D` escape를 푼 뒤 해석한다. ADXL 진동 샘플은 escape를 풀지 않는다. 수신기 함수는 `unescape_bytes`, `decode_vibration_samples`, `decode_piezo_samples`다.

초음파 H는 시간 파형이 아니다. 12바이트 헤더 뒤에 float32 little-endian 320개, 합계 1292바이트다. 헤더 8번 바이트가 시작 주파수(kHz), 9번 바이트가 간격(Hz)이다. 길이가 1292가 아니면 escape를 한 번 풀어 다시 확인한다. 위상 정보가 없으므로 RAW 시간 파형과 FFT 왕복 검증 대상이 아니다.

### FFT peak

기본 창은 Blackman이다. Hann, Hamming, Rectangular, Blackman-Harris, Flat Top, Bartlett, Kaiser(β 기본 8.6)가 있다.

순서 (`fft_peak`, 수신기는 `calculate_fft`):

1. 선택 구간에서 평균을 뺀다.
2. 창 함수 `w`를 곱한다.
3. `rFFT` 크기에 coherent gain `Σw`를 적용한다.
4. `2|rFFT|/Σw`가 단측 peak다. DC와 짝수 N의 Nyquist는 2배를 하지 않는다.

정현파 한 개의 peak가 시간 영역 진폭과 맞도록 맞춘 값이다. 이 peak를 `√2`로 나누면 그 bin의 RMS다.

### 주파수 영역 필터

HPF, LPF, Notch는 패킷 하나의 rFFT에 크기 응답을 곱한 뒤 irFFT로 되돌린다. 위상은 0이다. 패킷 경계를 주기로 보기 때문에 양 끝에서 누설이 생길 수 있다.

- HPF, LPF: Butterworth 크기. 차단 주파수는 −3 dB. 차수 1~12.
- Notch: 가우시안 억제. `notch_width`는 반치전폭(FWHM).
- LPF를 자동으로 두면 차단은 `Fs/2`라서 사실상 감쇠가 없다.

발생기는 `spectral_filter`, 수신기는 `apply_spectral_filters`다. RAW용과 FFT용 체크가 따로 있다.

### MEMS 스케일과 보정

`mems_lsb_scale.json`의 `g_per_lsb`가 1 LSB당 g다. 없으면 `1/256`(0.00390625). 허용 범위는 0 초과 10 이하다. LSB/g는 그 역수다.

`mems_frequency_sensitivity.json` 보정은 FFT 표시에만 쓴다.

```
f_real = f_measure / 1.014
S(f) = 0.99                         (f ≤ 60 Hz)
S(f) = 1.07 − 0.0005 × f            (60 Hz < f ≤ 360 Hz)
S(f) = 0.89                         (f > 360 Hz)
G_real(f) = G_measure(f) / S(f)
```

주파수 보정과 감도 보정은 각각 끌 수 있다. Count Peak 모드에서는 감도 나눗셈을 하지 않는다. 함수는 `mems_sensitivity`, `corrected_mems_fft`다.

속도 표시는 bin마다 다음이다. DC는 0이다.

```
v_RMS[mm/s] = g_RMS × 9806.65 / (2πf)
```

### SRSS

SRSS는 주파수마다의 곡선이 아니다. X, Y, Z 단측 peak로 만든 전체 AC RMS 숫자 하나다. FFT 그래프에는 그 높이의 가로 점선(`#9467BD`)으로 그린다. RAW 시계열은 없다.

`srss_axis_power(peak, n, window)`:

```
P_axis = Σ(weight × A_peak²) × (Σw)² / (N × Σw²)
SRSS   = √(P_X + P_Y + P_Z)
```

DC 가중치는 0이다. 짝수 N의 Nyquist 가중치는 1이고, 나머지 bin은 0.5다. 세 축의 Fs, 샘플 수, FFT 길이, 주파수 축이 같아야 한다. 하나라도 다르면 선을 그리지 않고 `SRSS: 완전한 XYZ 데이터 없음`을 보여 준다.

FFT 평균이 켜져 있으면 진폭 곡선을 먼저 평균한 뒤 SRSS를 내지 않는다. 패킷마다 SRSS를 구한 다음 그 숫자를 평균한다.

표시 단위는 현재 FFT 단위를 따른다.

| FFT 표시 | SRSS 단위 |
| --- | --- |
| Count Peak | Count RMS |
| g Peak, g RMS, 자동 g | g RMS |
| mm/s RMS | mm/s RMS |

수신기는 g RMS와 mm/s RMS 눈금이 이미 peak/`√2`이므로, SRSS에 넣기 전에 `√2`를 곱해 peak로 되돌린다.

### FFT / IFFT 검증

`fft_roundtrip_diagnostic`은 표시용 정규화와 별개다.

1. 입력 실수 배열을 `np.fft.fft`로 양측 복소수 스펙트럼에 보낸다.
2. 같은 계수를 `np.fft.ifft`로 되돌린다.
3. 양측 크기는 `fftshift`한 `|FFT|/N`이다.
4. 단측 크기는 DC와 짝수 N Nyquist를 제외하고 2배다.

PASS 조건은 복원 실수부와 입력이 `rtol=1e-10`, `atol=1e-8`로 같다. 최대 오차, RMS 오차, 잔류 허수를 같이 보여 준다. 평균 제거, SRSS, g·mm/s 환산은 이 검사에 넣지 않는다. 초음파 H는 위상이 없어 검사하지 않는다.

### 회전 부품 개수 후보

RPM을 Hz로 바꾼 뒤 2~48배 차수를 기본 주파수로 두고, FFT 국부 피크가 1~5차 고조파와 맞는 정도를 점수로 매긴다. 상위 5개 후보다. 부품 종류를 확정하지 않는다. 발생기는 `rotating_candidates`, 수신기는 `estimate_rotating_counts`다. 유형 목록(블레이드, 기어, 플런저, DC 정류자)은 표시용이다.

## 발생기 V048

한 장치 분량의 저장 파일을 읽어, 고른 패킷부터 MQTT로 반복 송신한다. 그래프는 송신 전에 그 파일을 미리 보는 창이다.

메인 창은 Tkinter `Generator`다. `📈 RAW / FFT 그래프 열기`를 누르면 별도 Qt 프로세스 `run_pyqtgraph_window`가 뜬다. Matplotlib `Figure`는 화면에 그리지 않고, 선 데이터를 만든 뒤 큐로 Qt에 넘긴다. Qt가 늦으면 오래된 프레임은 버리고 최신만 그린다.

### 파일 입력

센서마다 파일 하나다. 체크를 끄면 그 센서는 송신하지 않는다.

| 센서 | 읽는 함수 | 내용 |
| --- | --- | --- |
| PIEZO | `load_piezo_templates` → `load_piezo_csv` 또는 JSON | JSON, JSONL, 수신기 HEX CSV |
| ADXL | `load_adxl_templates` 또는 `load_adxl_csv_xyz` | JSON/JSONL, 또는 X/Y/Z CSV 세 개 |
| 초음파 | `load_ultrasonic_templates` | JSON 또는 수신기 HEX CSV |

ADXL CSV는 행의 축, seq, 시각으로 X/Y/Z를 한 세트로 맞춘다. `recover_adxl_hex_prefix`는 깨진 HEX의 앞쪽 완성 16bit 단어만 남긴다. 뒷부분을 추측하거나 0으로 채우지 않는다. 이렇게 줄인 패킷은 `_partial_recovered`가 붙고, 미리보기만 되며 `_publish`에서 제외된다. 체크 이름은 `손상된 HEX 앞부분 자동 복구(미리보기)`다.

### 미리보기 이동

`preview`가 현재 센서의 현재 인덱스를 그린다. `navigate`, `goto_index`로 패킷을 옮긴다. ADXL 한 칸은 X/Y/Z 세트다. 초음파는 스펙트럼 320점만 그리고 FFT 서브플롯은 숨긴다.

위치 표시 예: `ADXL: 3 / 120 패킷 | 선택 시작점: 3 | 유효 축: X,Y,Z`.

### MQTT 송신

기본 브로커는 `127.0.0.1:1883`, QoS 1이다. User, Password 칸이 있다. 비어 있으면 인증을 넣지 않는다.

기본 토픽은 PIEZO·ADXL `V/{mac}`, 초음파 `D/{mac}`다. `{mac}`은 MAC 덮어쓰기가 켜져 있으면 입력 MAC, 꺼져 있으면 패킷의 `dvicMacAddr`다. `{device}`는 Device ID다.

`start`는 체크된 센서마다 스레드 `_worker`를 만든다.

- 시작 인덱스는 지금 보고 있는 패킷이다. 파일 끝 다음은 1번이 아니라 그 시작 인덱스로 돌아간다.
- 자동 주기가 켜져 있으면 주기(ms)는 `numofsample / samplerate × 1000`이다. 초음파는 자동 주기가 없고 기본 10000 ms다.
- ADXL은 X, Y, Z 순서로 보내고, 축 사이에 `xyz_gap`(기본 5 ms)을 둔다.
- Jitter는 주기에 ±값을 더한다. Loss%는 그 확률로 publish를 건너뛰고 Drop에 센다. 둘 다 기본은 꺼짐이다.
- 진동 seq 자동이 켜져 있으면 `seq`를 `SequenceState`로 다시 만든다.
- `with_replay_metadata`는 송신 직전에만 `acqStatus`, `apSsid`, `apRssi`가 비어 있으면 `OK`, `REPLAY`, `0`을 넣는다. 파일에 값이 있으면 그대로 둔다. 템플릿과 CSV는 수정하지 않는다.
- 초음파 `tick 증가`가 0이 아니면 송신 횟수만큼 tick을 더한다.
- 카운터는 `Publish / PUBACK / Drop`이다. `_on_publish`가 PUBACK를 센다.

`test_connection`은 붙었다가 바로 끊는다. `stop`은 스레드를 세우고 브로커 연결을 닫는다.

### PIEZO 미리보기

`_plot_piezo`. 기본 단위는 mV. Vmax 3.89 V, Amax 4096, 감도 100 mV/g.

```
K = 1000 × Vmax / Amax          (mV/Count)
```

RAW 표시는 항상 패킷 평균을 뺀 값이다. FFT는 평균을 뺀 Count로 `fft_peak`를 낸 뒤 단위를 곱한다.

| 단위 | RAW | FFT |
| --- | --- | --- |
| Count | `C − mean(C)` | Count Peak |
| mV | 위 × K | Count Peak × K |
| g RMS | 위 × K / 감도 | Count Peak × K / (감도 × √2) |
| mm/s RMS | RAW는 g | bin별 `g RMS × 9806.65 / (2πf)` |

시간 전체 g RMS는 상태 문구에 `√mean((g−g_mean)²)`로만 적는다. 별도 RMS 차트는 없다. FFT 창은 Blackman, Hann, Hamming, Rectangular 네 개다.

### ADXL 미리보기

`_plot_adxl`. 축 색은 X `#1f77b4`, Y `#2ca02c`, Z `#d62728`, SRSS `#9467BD`다. X/Y/Z/SRSS 체크가 있다.

RAW 단위: 자동(g/mg/µg), Count, g, mg, µg. 자동은 세 축이 같이 본 최대값으로 고른다. 0.001 g 미만이면 µg, 1 g 미만이면 mg, 그 외는 g다. 축마다 단위를 따로 고르지 않는다.

시간 영역 AC g RMS는 `std(Count / LSB/g)`이고, 화면 아래 `축별 전체 구간 AC g RMS`에 숫자로만 나온다.

FFT 단위: 자동(g RMS), Count Peak, g Peak, g RMS, mm/s RMS. g 계열은 Count Peak에 `g_per_lsb`를 곱하고, RMS는 다시 `√2`로 나눈다. 그 다음 주파수·감도 보정을 적용한다. mm/s는 보정된 g RMS와 보정된 주파수로 계산한다.

Window N은 전체, 1024, 2048, 4096, 8192다. 전체보다 작으면 패킷 가운데 구간만 쓴다.

### 초음파 미리보기

`_plot_ultrasonic`. 320개 원본 값을 kHz 축에 그대로 그린다. FFT를 다시 하지 않는다. 제목에 시작 kHz, step Hz, 최댓값 위치를 적는다.

### FFT 평균

`_average_fft_counts`. 기본은 꺼짐. 개수는 2, 4, 8, 16, 32, 64, 128, 전체다. 현재 패킷부터 뒤로 M개다.

같은 주파수 bin의 peak 진폭을 산술평균한다. RAW 샘플을 평균하지 않고, 평균 곡선을 MQTT로 보내지 않는다. Fs나 길이가 다른 패킷은 빼고 `제외` 횟수를 보여 준다. ADXL은 축마다 따로 평균한다. SRSS만 패킷별 RMS의 평균이다.

### 그래프 조작

Qt 창과 Tk 쪽 계산이 같은 규칙을 쓴다.

- 휠: X, Y 함께 확대
- 왼쪽 버튼을 누른 채 휠: X만
- 오른쪽 버튼을 누른 채 휠: Y만
- 왼쪽 드래그: 이동
- 클릭: 커서 고정. 같은 X를 따라간다
- 오른쪽 클릭 메뉴: 확대, 전체 보기, 이미지 저장
- RAW Y, FFT Y에 min/max를 넣고 `Y축 적용` 또는 `Y축 고정`
- RAW Y 대칭로그, FFT X 로그, FFT Y 로그
- `그래프 전체 보기`는 축 범위만 풀고, 단위·필터·평균·보정은 유지한다

`FFT 과정 / IFFT 검증`은 `show_fft_diagnostic_tk` 또는 Qt 대화상자다. ① 입력, ② 양측 FFT, ③ 단측 FFT, ④ IFFT 복원과 PASS/FAIL을 보여 준다.

## 수신기 V048 파일

MQTT 또는 시리얼로 JSON 패킷을 받아 분류하고, 최신 파형을 그래프에 그리며, 선택하면 CSV로 남긴다. 같은 창에서 센서에 설정·START·STOP을 보낼 수 있다.

클래스 `App`이 메인이다. 그래프는 프로세스 네 갈래다.

| 버튼 | 프로세스 | 엔진 |
| --- | --- | --- |
| ADXL 그래프 | `_pyqtgraph_viewer_process` | original NumPy |
| PIEZO 그래프 | 같은 뷰어, mode PIEZO | original |
| PIEZO SciPy 비교 | 같은 뷰어 | `scipy_filter_signal`, `scipy_fft_comparison` |
| 초음파 그래프 | `_pyqtgraph_ultrasonic_viewer_process` | 스펙트럼 원본 |

부모는 최신 스냅샷만 큐에 넣는다. 뷰어가 바쁘면 이전 스냅샷을 버린다. 화면 갱신 주기는 250 ms다. 점을 너무 많이 그릴 때는 `_decimate_xy`로 1200점 안쪽으로 줄인다. 계산 원본은 줄이지 않는다.

### 통신

`connect`가 MQTT 또는 SERIAL을 고른다.

- MQTT 기본 브로커 `192.168.1.62:1883`, 토픽 `V/#,D/#`, QoS 1. 토픽은 쉼표, 세미콜론, 줄바꿈으로 여러 개다 (`parse_mqtt_topics`). 연결 후 그 토픽과 `S/#`를 구독한다.
- 시리얼 기본 230400 baud. `_serial_read_loop`가 바이트를 모으고 `_extract_json_objects`가 JSON 객체를 잘라 낸다.

`on_message`와 시리얼 쪽 모두 `_process_payload`로 들어간다.

1. UTF-8 JSON으로 파싱한다. 실패하면 JSON 오류 카운트만 올린다.
2. `samplerate`와 `numofsample`이 있으면 `classify_vibration`으로 PIEZO 또는 ADXL-X/Y/Z다.
3. 둘 다 없고 `sensorData`가 있거나 토픽에 ultrasonic이 있으면 `classify_ultrasonic`으로 H다.
4. `dvicMacAddr`를 장치 목록에 넣는다 (`SensorRegistry`).
5. 샘플을 디코드해 `ADXLLatestStore` 또는 PIEZO 최신값, `UltrasonicLatestStore`에 넣는다.
6. CSV가 켜져 있으면 HEX는 디코드 실패와 관계없이 저장 큐에 넣는다.

ADXL은 X, Y, Z가 모일 때까지 `_queue_adxl_csv_item`에 붙잡아 둔다. 세 축의 장치, 샘플 수, 샘플링이 맞을 때만 한 세트로 저장한다.

### 저장 CSV

`_csv_writer_loop`가 별도 스레드다. 측정 START 여부와 상관없이, CSV 저장이 켜져 있으면 수신 즉시 쓴다. 행마다 flush한다.

세션 폴더는 `data_csv/YYYYMMDD_HHMMSS/`다. 파일은 `{장치}_{종류}_sensorData_hex.csv`와 `_decoded_samples.csv`다.

공통 열: packet_no, received_at, source, dvicMacAddr, gwMacAddr, sensor_type, axis, seq, tick, batteryRmin, samplerate, numofsample, payload_bytes, acqStatus, apSsid, apRssi.

HEX 파일은 `sensorData_bytes`, `sensorData_hex`를 더한다. decoded 파일은 샘플 개수와 샘플 배열을 더한다. 초음파 decoded는 `minKhz`, `intervalHz`, `freq_start_kHz`, `freq_end_kHz`를 더한다.

같은 세션에 헤더가 다른 옛 파일이 있으면 덮어쓰지 않고 이름에 `_v040`을 붙여 새 파일을 만든다.

### 센서 명령

설정은 MQTT면 `S/{MAC}`에 retain, QoS 1로 나간다. 시리얼이면 같은 JSON을 포트로 쓴다. 길이가 1024바이트를 넘으면 거절한다. 보내기 전에 고른 MAC으로 할지 확인한다. MAC은 수신 목록에서 고르거나 직접 입력한다.

`SENSORTYPE` (`_current_sensortype`):

| 값 | 의미 |
| --- | --- |
| 0 | STOP |
| 1 | PIEZO normal |
| 2 | ADXL normal |
| 3 | PIEZO collection |
| 4 | ADXL collection |

normal과 collection은 같은 샘플 설정을 싣는다. PIEZO는 `PIEZO_SAMPLE_RATE`, `PIEZO_SAMPLE_COUNT`, `PIEZO_GAIN`. ADXL은 `MEMS_SAMPLE_RATE`(레지스터 코드, 예: `0F`), `MEMS_SAMPLE_COUNT`. 공통으로 `COMMPATH`, `SENSING_PERIOD`(초)가 있다.

샘플 세트는 UI에서 `Fs + N` 한 줄로 고른다.

- PIEZO Fs: 512, 1280, 2560, 5120, 12800, 25600 Hz
- ADXL Fs: 100, 200, 400, 800, 1600, 3200 Hz. 코드는 `ADXL_RATE_TO_CODE`의 `0x08`~`0x0F`
- N: 1024, 2048, 4096, 8192

`START`는 collection 코드 3 또는 4를 retain으로 보낸다. MQTT에서 `STOP`은 `_mqtt_collection_stop` 세 단계다. 각 단계마다 PUBACK를 10초까지 기다린다. 한 단계가 실패하면 다음으로 가지 않는다.

1. `SENSORTYPE=0` retain
2. 빈 payload로 retain 삭제
3. normal(PIEZO 1, ADXL 2) retain

시리얼 STOP은 `SENSORTYPE=0` 한 번이다. `조회`는 현재 설정을 요청하고, 응답이 오면 `_apply_current_sensor_config`가 화면 값을 맞춘다.

AP 설정 창 `open_ap_config`는 SSID 등 AP 항목을 따로 보낸다.

### PIEZO 그래프 단위

기본 Vmax 3.89 V, Amax 4096, 감도 100 mV/g. 장치마다 다른 Vmax는 `piezo_device_voltages.json`에 저장한다. 새 MAC의 첫 유효 패킷은 기본 전압으로 등록된다.

```
v(t)[mV] = 1000 × Vmax / Amax × (C(t) + Amax/2)
g(t) = v(t) / 100
g_RMS = √mean((g − g_mean)²)
```

이 절대전압은 16bit 수신 코드에 12bit 눈금을 시험 적용한 값이다. AC RMS에서는 DC 바이어스가 평균 제거로 빠진다.

표시 모드:

- Count
- 전압(V). FFT는 V Peak
- 센서 규격 g. FFT는 g RMS/bin
- g peak-to-peak 스케일
- 보정 g. 장치·축마다 `counts_per_g`를 잡아 RAW를 나눈다
- 속도 RMS. RAW는 순간 가속도 g, FFT만 mm/s RMS/bin

RAW로 그리는 배열만 평균을 빼서 세로 중심을 0에 둔다. CSV, FFT 입력, RMS 숫자는 그 평균 제거 전의 값을 쓴다. HPF가 켜지면 필터 자체가 DC를 없앤다.

추가 표시:

- 패킷 peak-to-peak를 mV로 보여 주고, 패킷마다 max 합과 min 합의 차이를 누적한다. 필터와 0점과 따로 계산한다.
- 선택 단위의 측정값과 그 단위의 식만 보여 준다.
- FFT 최대 bin 주파수로 1주기 구간을 RAW 위에 표시한다.
- 0점 모드는 자동(패킷 평균)과 수동이다. 수동 값은 복사해 넣을 수 있다.

보정은 `calibrate_current_g_rms`다. 기준 g RMS와 현재 Count RMS로 `counts_per_g`를 만들고, 축마다 켜고 지울 수 있다.

### ADXL 그래프 단위

RAW와 FFT 단위는 따로 고른다. 수동으로 고른 값은 수신 중에도 유지된다.

RAW: 자동(g/mg/µg), ADC Count, g, mg, µg. 기본 선택은 g다. 자동일 때는 X/Y/Z를 한 눈금으로 본다. `g = Count × g_per_lsb`.

FFT: g RMS(기본), Count Peak, g Peak, mm/s RMS.

```
g Peak = Count Peak × (g/LSB)
g RMS  = g Peak / √2
```

주파수·감도 보정은 g 계열 FFT에 적용된다. RAW Count 파형에는 적용되지 않는다.

축 색과 SRSS 점선은 발생기와 같다. SRSS 체크를 꺼도 세 축 스펙트럼이 맞으면 계산은 하고, 선만 숨긴다. 제목은 `SRSS = 값 단위`다.

### 초음파 그래프

320 bin을 시작 주파수와 간격으로 그린다. 다시 FFT하지 않는다. 호버로 bin 값을 읽는다.

### 그래프 안의 분석 도구

뷰어 옵션 스크롤 영역에 모여 있다.

- FFT Window. 기본 인덱스 3이 Blackman. Window N은 수신 샘플 수에 맞춰 `allowed_fft_window_sizes`로 제한하고, `select_fft_segment`가 가운데를 자른다.
- Kaiser β.
- HPF, LPF, Notch. RAW와 FFT에 각각 적용.
- FFT X 로그, FFT Y 로그. RAW Y 대칭로그와 선형 구간 기준값.
- Y축 min/max 고정, 자동, 전체 보기.
- 휠, 왼쪽+휠, 오른쪽+휠, 드래그, 클릭 고정 커서. 고정 커서는 새 패킷이 와도 같은 X를 따라간다.
- `FFT 과정 / IFFT 검증` 버튼. `open_fft_diagnostic`.
- RPM과 축을 넣고 회전 부품 개수 후보를 표시. 후보 위치에 마커를 남긴다.

SciPy 비교 창은 `sosfiltfilt`와 `iirnotch`를 쓴다. 원본 FFT 필터와 크기 응답이 다르다. 저장 파일과 MQTT에는 영향을 주지 않는다. 이 비교 창이 없으면 수신기는 SciPy 없이 NumPy만으로 동작한다.

### 통계와 로그

`Stats`와 `Bucket`이 패킷 길이, 수신 간격, 무시 건수, JSON 오류를 센다. 이 통계 표는 메인 화면에서 빼 두었고 내부 카운트는 남아 있다. 센서 로그는 수신·송신 방향을 남기고 지울 수 있다.

## 두 프로그램이 맞물리는 방식

1. 수신기가 CSV를 저장한다.
2. 발생기가 그 HEX CSV를 PIEZO 파일 또는 ADXL X/Y/Z 세 파일로 읽는다.
3. 발생기가 고른 패킷부터 `V/{mac}` 또는 `D/{mac}`로 다시 보낸다.
4. 수신기가 같은 브로커에서 그 토픽을 구독하면 그래프에 다시 나타난다.

발생기 기본 브로커는 `127.0.0.1`, 수신기 기본 브로커는 `192.168.1.62`다. 같은 브로커를 가리켜야 서로 보인다.

발생기가 하는 미리보기 환산은 수신기 그래프와 같은 식을 미리 보여 주는 것이다. 수신기만 가진 것은 실시간 구독, 시리얼, 센서 명령, 모드 A 3단계 STOP, CSV 기록, 장치별 PIEZO 전압, g RMS 보정, SciPy 비교 창이다. 발생기만 가진 것은 파일 재생, 주기·jitter·loss, seq 재작성, MAC 덮어쓰기, 재생용 상태 기본값, 손상 HEX 앞부분 미리보기 복구다.
