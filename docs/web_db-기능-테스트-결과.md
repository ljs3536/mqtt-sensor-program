### 예시 데이터

수신기 V057 CSV 형식(상태 메타데이터 열 포함, 엑셀에서 열림)으로 만들었다. 값을 미리 알 수 있게 사인파를 넣었다.

| 파일 | 내용 |
| --- | --- |
| `AABBCCDD0001_ADXL-X/Y/Z_sensorData_hex.csv` | 3200 Hz, 4096점. X 0.5 g + 315 Hz 0.05 g, Y 0.3 g, Z 0.2 g + 중력 1 g, 모두 100 Hz. 6세트, 세트마다 15%씩 커짐. 4번 세트는 Z 없음 |
| `PZ0000000001_PIEZO_sensorData_hex.csv` | 25600 Hz, 8192점, 1000 Hz, 진폭 1000·2000·3000 Count, 3패킷 |
| `US0000000001_ULTRASONIC_sensorData_hex.csv` | H 1292바이트(시작 20 kHz, 간격 100 Hz), 40 kHz 봉우리, 2패킷 |
| `broken/…ADXL-X…csv` | X 2번 행 HEX 끝 10글자를 자름(앞부분 복구 확인용) |
| `piezo_packets.json` | PIEZO 패킷 3개(MAC `PZJSON000001`), 한 줄에 하나 |
| `plan_A.png`, `plan_B.png`, `plan_A2.png` | 평면도 800×500, 600×400, 교체용 1000×600 |

시험 파일과 스크립트는 임시 폴더에 있다(저장소에 넣지 않음). 다시 돌리려면 저장소에 옮겨야 한다.

### 시험 순서

1. 수신 모니터에서 연결(QoS·CSV), 연결 해제, QoS 2로 다시 연결
2. 데이터 분석 CSV에서 예시 파일 열기 → 그래프 옵션 → 저장 설정 → 시간 이력 → 송신(세 센서 동시, MAC 덮어쓰기, Loss, tick)
3. 수신 모니터에서 받은 데이터 그래프, 이름, 한계, 센서 명령
4. 센서 데이터 분석(DB)에서 열기, 시간 이력, 초음파 재송신
5. 설정: 장치, CSV 일자별 통계, 평면도 배치
6. 통계, 센서 현황(1분 상태 기록을 기다려 최근 알림까지)
7. 화면 테마, 서버 재시작 뒤 자동 연결

## 시험하지 않은 것

| 항목 | 이유 |
| --- | --- |
| 실제 센서와 펌웨어 | 장비가 없음. 센서가 명령(QoS 1, 끝 CR LF 없음, STOP 3단계)을 받아들이는지는 실제 센서로 확인해야 한다 |
| 운영 브로커, Docker 이미지(`sensor-web.tar`) | 로컬 서버로만 시험. 이미지를 새로 만들어 운영 서버에서 한 번 확인 필요 |
| 여러 사람이 동시에 쓰기 | 서버 메모리 상태를 같이 쓰는 한계는 이미 문서에 있음(`웹-기능상세.md` "메모리에만 있는 것") |
| 여러 날에 걸친 동작 | 자정 뒤 자동 통계는 스레드 대신 같은 함수(`update_statistics`)를 직접 불러 확인. 상태 '지연·끊김'은 판정 함수로 확인 |
| Chrome 밖의 브라우저, 좁은 화면 | Chrome 1600×1000만 |
| 1 LSB·MEMS 보정 저장이 통계 값을 바꾸는지 | 저장·되돌리기만 확인 |

## 시험 중 알게 된 것(고치지 않음)

| 항목 | 내용 |
| --- | --- |
| 분석 화면 회전 부품 후보 | 서버는 RPM 1800 기본값으로 후보를 계산하지만, 화면에 RPM 입력칸과 결과 표시가 없다. `웹-프로그램-기능대조.md`는 "회전 부품 후보(RPM, 유형, 축) O"로 적혀 있다 |
| PIEZO와 ADXL을 동시에 재송신 | 송신 seq 카운터를 같이 써서 X와 Y 사이에 PIEZO가 끼면 seq가 이어지지 않는다. 수신 쪽 CSV packet_no와 DB 세트가 어긋나 그 ADXL 세트가 통계에서 빠진다. 발생기 v070과 같은 동작(`next_seq` 동일). 센서 하나씩 보내면 생기지 않는다 |
| 대문 'ⓘ 판정 기준' 문구 | "경보: 진동(SRSS 전체 평균) ≥ 한계"라고 보이지만 실제 판정은 가장 최근 통계 한 줄이다(문서와 코드는 '최근 한 줄'로 같음) |
| 분석 화면 '로그 지우기' | 칸을 비우기만 한다. 서버는 "로그를 지웠습니다" 한 줄을 남기지만 화면은 다음 갱신 때 보인다(수신 모니터는 바로 보임) |
| `/studio`를 열 때 | DB에서 열기 전, 분석 화면과 같이 쓰는 서버 메모리의 패킷(예: `/generator`에서 연 CSV)이 먼저 보인다. 이미 문서에 있는 '메모리 공유' 한계와 같은 것 |
| 하루 통계와 시간 이력의 SRSS | 같은 세트라도 값이 다르다(예: `import_csv` 통계 평균 9.254 mm/s, 시간 이력 평균 9.200 mm/s). 통계는 FFT SRSS(보정 없음), 시간 이력은 Welch PSD(주파수·감도 보정 포함)라 계산이 다르다. 설계대로다 |
| 확인 창과 탭 | 확인(confirm) 창은 앞에 있는 탭에서만 뜬다. 뒤 탭에서 버튼을 누르면 탭을 앞으로 가져올 때까지 기다린다(Chrome 동작) |
