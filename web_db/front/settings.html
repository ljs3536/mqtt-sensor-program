장치 이름 / 진동 구간

표시 이름은 통계와 분석 MAC 목록에 붙고, 위치(설치 장소)는 통계 화면 이름 아래에 보입니다. 이름이 없거나 '표시'를 끈 센서는 센서 현황·분석·통계에 보이지 않습니다(수신 저장·통계 계산은 계속, 이 표와 센서 수신 모니터에는 보임). 진동 구간(mm/s RMS, ISO 20816-3 Group 2 강성 지지)은 양호 < 양호 상한 ≤ 주의 < 주의 상한 ≤ 경고 < 위험 기준 ≤ 위험입니다. 기본 1.4 / 2.8 / 4.5이고, 양호·주의 상한을 비워 두면 위험 기준의 같은 비율로 자동 계산합니다(위험 기준 15면 4.67 / 9.33). 위험 기준은 그래프의 SRSS 한계선과 같은 값입니다. 사진(MAC마다 한 장)은 센서 현황에서 센서를 누르면 정보 카드 위쪽에 보입니다.

    통계 계산 기준

    매시간 통계와 센서 현황 경보가 쓰는 기준입니다. 저장하면 새 버전으로 남고, 그 기준으로 지금까지 받은 데이터를 다시 계산합니다(계산하는 동안에도 수신 저장은 그대로 됩니다). 분석 화면 그래프의 서랍 설정과는 따로입니다.

    필터 (FFT·PSD 계산 전)

    세트의 Fs/2 이상인 필터는 그 세트에서만 빠집니다(계산 메모에 남음).

    Welch PSD

    속도 RMS = √(Σ 속도 PSD × Δf), SRSS = √(X² + Y² + Z²). 분석 데이터 저장(ZIP)과 같은 계산입니다.

    CSV 데이터 가져오기

    수신 CSV 폴더에 쌓인 데이터(MEMS X/Y/Z, PIEZO, 초음파)를 DB에 넣습니다. 이미 DB에 있는 패킷(같은 MAC·축·수신 시각)은 건너뛰므로 여러 번 눌러도 두 번 들어가지 않습니다. 가져오는 동안에도 센서 수신과 저장은 그대로 됩니다. 다 끝나면 위 지금 기준으로 다시 계산을 눌러 통계를 만드세요. 가져온 데이터는 센서 데이터 분석 화면에서도 열 수 있습니다.
